# متجر صدارة شي إن | Sadara SHEIN Platform

التطبيق والموقع الرسمي لمؤسسة **صدارة** لخدمات الوساطة والتسوق الإلكتروني وتتبع شحنات شي إن (SHEIN Express Proxy).

## المميزات
- واجهة مستخدم متوافقة بالكامل مع كافة الأجهزة (Responsive Mobile-First RTL).
- نموذج توريد وسيط شي إن السريع وتتبع حالات الطلب.
- نظام التسوق والعمولات المدمج لمسوقي صدارة.
- متصل بقواعد بيانات وتخزين Supabase Storage (`platform-files`).

## النشر
المشروع جاهز للمزامنة والتأكيد المباشر عبر Vercel مجاناً.
